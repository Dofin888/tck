# Tck

Проверка таблиц Excel и CSV: пустые значения, дубликаты, типы данных, числовой диапазон, допустимые значения. Результат можно экспортировать в Excel или CSV.

## Запуск из исходников

    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    python ui.py

## Готовая программа

Скачай tck_v1.exe из раздела Releases (только Windows).
